# JRA条件別モデル研究用データ（2026年5月2日〜9月27日）

44開催日・全1,464レースの事後再構成データです。芝780、ダート635、障害49を保存しています。出走表19,692頭、実出走19,617頭、公式取消・除外75頭、対象レース前の過去走72,604行です。

| ファイル | 内容 |
| --- | --- |
| `races.jsonl.gz` | レース一覧、公式結果URL、日付分割、監査準備時点の状態 |
| `features_YYYY-MM.jsonl.gz` | 出走表と対象日前の過去走、時計、斤量、通過順、観測された区間ペース、コース・環境、欠損と出典 |
| `outcomes_YYYY-MM.jsonl.gz` | 対象レース結果、払戻の数値セル、確定オッズ。ラベル・事後比較専用 |
| `audit_preparation_YYYY-MM.jsonl.gz` | 頭数・履歴件数・欠損・取得状況と準備時の判定。正式な学習承認ではない |
| `environment_venue_days.jsonl.gz` | 122会場日分の馬場環境観測と取得時刻。発走前の保存は未証明 |
| `source_index.jsonl.gz` | 原典19,659件のURL、取得手順・時刻・文字コード・原文SHA-256 |
| [manifest.json](manifest.json) | レース・出走馬・過去走の総数と保存ファイルのSHA-256 |

公開用の研究データには、観測した事実と解析に必要な値を収録しました。JRAのHTML・PDFの原文、原文の長文抜粋、作業端末の絶対パスは含みません。原文のSHA-256は出典の識別に使い、別時点の取得結果が元の原典と同一とは見なしません。

このアーカイブでは監査準備で学習候補になった298レースを識別できます。候補は学習181・検証58・テスト59です。監査を通らなかったレースも資料として収録し、個別の馬を除外したり、欠損に推定値を入れたりしていません。アーカイブは学習完了・精度改善・本番適用を意味しません。

Python 3.9以降で保存ファイルのSHA-256、件数、レースIDの対応を検証できます。

```sh
python3 research/datasets/jra-20260502-20260927/verify_dataset.py
```

JSON Linesは1行が1件です。例：

```sh
gzip -dc research/datasets/jra-20260502-20260927/races.jsonl.gz | head
```
