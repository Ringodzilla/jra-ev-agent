# 保存済み勝率の識別力診断

`python scripts/diagnose_saved_probabilities.py --run-dir <発走前run> --retrospective <公式回顧JSON> --output <新規診断JSON>`

保存された勝率だけを、一律勝率と保存時単勝オッズの逆数を正規化した市場確率へ照合する。モデルの推論・買い目生成・係数変更は行わない。回顧に記録された予測成果物のSHA256、発走前の発行時刻、同一レースの全頭・全着順を検証する。欠けた値や矛盾した来歴は補完せず拒否する。

出力は勝者の対数損失、多クラスBrierスコア（全馬の二乗誤差の和）、エントロピー、実効頭数、EV1.1以上の候補集合の一致である。市場確率は比較用であり構造勝率へ混ぜない。結果ラベルも診断だけで使い、予測入力へ返さない。保存確率の丸め残差は評価指標に限り正規化し、原値は明記して保持する。

2026年菊花賞の診断では、EV1.1以上の候補は現行モデル・全馬一律の両方で同じ14頭だった。勝率4.60〜7.35%、実効頭数17.89/18という分布と合わせ、この例ではEV選別がオッズに強く左右されている。単一レースの結果から長期成績や適正な係数は決めない。

現行 `temperature` はスコアに掛ける倍率であり、一般的な `Softmax(S/T)` の温度とは逆方向に作用する。今回の保存スコア幅に倍率1.15を掛けた値は約0.468であり、無ノイズSoftmaxでの最大・最小確率比は約1.596になる。この値をGaussianノイズ付きMonte Carloの上限、または全レースの上限として使わない。倍率の変更だけでは誤った能力順位も強調し得る。

次のモデル比較は、同一の検証可能な発走前入力、時系列分離、レース当たり1つの固定スナップショットで行う。芝・ダート×距離別の件数、対数損失・Brier・候補集合・固定購入方針の収支を記録する。全馬一律・市場との比較を併記し、採用基準は評価前に固定する。来歴不一致のrunを勝手に修復・再構築して発走前予測として扱わない。未検証係数の本番採用や追加の穴馬足切りで診断問題を隠さない。
