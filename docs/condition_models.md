# 芝・ダート・距離別に育てるモデルの方針

## 基本形

これまで育てた共通の特徴量・能力評価・展開・確率計算を基本形として残す。
芝・ダートや距離に応じた改善は、この基本形を継承する条件別の差分として追加する。
距離ごとに予測パイプライン全体を複製せず、共通部分の改善と条件固有の改善を分けて管理する。

現時点の基本形の実装は以下にある。

- `src/feature_engineering.py`: 過去走の集計と能力・コース・斤量・騎手等の特徴量。
- `analysis/ev.py`: 展開シナリオの生成と `EVWeights`。
- `src/model.py`: `ModelWeights`、構造勝率、Monte Carlo、オッズ予測。
- `src/environment_prediction.py`: 昇格済み環境モデルによる最終logit補正。

「基本形として残す」は、現行モデルの精度が全条件で検証済みという意味ではない。
変更前のコード版・作業差分・設定・入力・出力のSHA256を固定し、候補との比較対象にする。
現行の芝3000mの出力が平坦だったという一例だけから、新係数や関数を本番へ追加しない。

## 条件別の拡張

| 層 | 担当する差分 | 適用範囲の例 |
| --- | --- | --- |
| 共通の基本形 | 全条件に共通する特徴量と計算手順 | 共通 |
| 馬場種別 | 芝・ダートそれぞれに固有の特徴量変換・重み | 芝、ダート |
| 距離 | 距離適性、持続力、展開評価、確率の分布の改善 | 芝3000m、ダート1700m |
| コース条件 | 検証で必要性が確認された競馬場等の差分 | 京都・芝3000m |

距離はメートルの数値で指定する。距離帯をまとめる場合は範囲と境界を設定に明記し、
「短距離」「長距離」の呼び名だけで適用しない。距離帯の区切り自体も検証対象とする。
障害は別の馬場種別として扱い、芝の平地向け差分を暗黙に適用しない。

各差分は識別子・版・親の基本形の版・適用条件・変更対象の関数またはパラメータ・
検証結果・本番採否を持つ。重複条件の優先順位を明示し、同じ効果を二重に加算しない。
専用差分が未検証・未登録なら、既存の基本形を使用し、専用モデルが未適用である理由を保存する。
不正な設定や曖昧な条件選択は、黙って別条件へ切り替えず検査エラーにする。

既存の `config/course_learning.json` / `src/track_bias.py` にある条件付きの展開・枠補正と
競合する別系統を増やさない。既存の差分も比較基準に含め、同じ効果の重複適用を検査する。
環境係数の学習・昇格は [既存の環境モデル規約](environment_model.md) に従う。

## 維持する計算契約

- analyzerが条件別特徴量・スコアを作り、simulatorが展開と統合する。役割分離は維持する。
- 構造勝率を市場オッズから独立に計算し、環境は既存の二段階確率式で扱う。
- EV = 的中確率 × オッズの式、券種別確率の区別、予算・締切・鮮度・承認ゲートを条件別に緩めない。
- オッズ下落予測や購入戦略を条件別に改善する場合も、能力評価・勝率の差分とは分離して検証する。
- 各成果物に基本形と適用差分の版、適用条件、入力根拠、未適用理由を保存し、再計算可能にする。

## 検証と本番採用

新しい条件別の関数やパラメータは研究用の候補として作り、同じ入力で基本形と比較する。
時系列で学習・検証・テストを分離し、条件別の件数、勝率の校正、対数損失・Brierスコア、
事前に固定した購入方針の回収率とリスクを記録する。単一レースの的中・不的中や回収率だけで採用しない。
採否基準は結果を見る前に定義し、サンプル不足・未評価は未検証として残す。

該当条件での改善と、非対象条件での基本形の再現性を確認してから本番へ明示的に採用する。
境界距離・芝とダートの取り違え・未登録条件の基本形へのフォールバック・二重適用・
未検証差分の本番混入は、ルーティング実装と同時に自動テストで強制する。

共通の基本形を更新する際は、既存の条件別差分も再評価し、親の版が異なる差分を自動で適用しない。
採用前の基本形と差分を保持し、再現とロールバックができるようにする。

## 実装時の順序

1. 現行の基本形と評価入力・出力を固定する。
2. 基本形へのフォールバックを持つ条件選択と、モデル来歴の出力を実装する。
3. 芝・ダート×距離の候補を一つずつ研究出力先で評価する。
4. 検証を通過した差分だけを本番へ採用する。

この文書は今後の拡張方針を定める。新しい条件選択器や専用係数の実装・本番採用を完了したものとは扱わない。
