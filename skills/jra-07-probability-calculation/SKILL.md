# 確率再計算

[工程仕様](../../docs/skill_workflow.md) の共通契約に従う。担当役割はsimulator。

- 入力JSON: 06の合格成果物と05の固定スコア、モデル版、環境補正。
- 出力JSON: probabilities, probability_checks, probability_lineage。
- 合格条件: 二段階の規定式と固定モデル版の実装の対応を照合し、同じ設定・入力から保存確率を再現して、全頭の確率和・範囲・有限性と来歴を確認する。環境段はp_final=Softmax(log(p_base)+environment_score)を検算する。
- 停止条件: 入力不一致、未承認補完、未昇格係数の本番適用。補正を独自に変更しない。

## 勝率の識別力を確かめる

- 確率和だけでなく、スコア幅、Softmaxへ渡す尺度、最小・最大勝率、一律1/頭数との距離を確認する。尺度の問題と、馬の能力順位が正しいかを区別する。
- 平坦な勝率で高オッズ馬のEVが膨らむ場合は、現象と計算経路を説明し、基本形の改善対象へ戻す。診断値を新しい足切り閾値や暗黙のNO_GO条件にしない。
- 鋭い分布や的中した順位へ合わせるために倍率を変更しない。精度改善は時系列で分けた複数レースで一律・市場の比較指標も併記して評価する。市場は比較用で構造勝率へ混ぜない。

- 現行基本形のp_baseは、temperatureを乗じたスコアへGaussian摂動を加えたSoftmax確率の平均である。規定の単純Softmaxそのものと等価だと説明せず、モデル版・倍率・ノイズ・試行数と規定式との差を残す。既存の再現検算に代えて別の推定法を独自採用しない。

- 展開固定の研究では P(勝利|展開) と P(勝利) を別に保存し、全体が展開頻度×条件付き勝率の和で再現されることを検算する。本線は明示指定または予測頻度から選び、馬券EVや結果で後付け選択しない。

- 本線の展開固定には統計的優位差を確認する。初回・追加・上限の試行数と有意水準・最小差を事前固定し、同一乱数系列で試行を追加する。繰り返し確認と複数ペース比較を考慮し、上限でも未確認なら本線を固定しない。MC誤差の減少と実レースでの精度・学習データ量を混同しない。手動指定は仮説比較として残し、未確認の最多ペースを確定済みとして渡さない。
